# Virtualisierte Nextcloud-Lösung

**SOL-Projekt – Planung und Umsetzung einer virtualisierten Nextcloud-Lösung mit Backup, Monitoring und schnellem Wiederanlauf**

## Projektziel

In diesem Projekt wird eine virtualisierte Nextcloud-Umgebung auf Proxmox aufgebaut.  
Die Lösung umfasst:

- Proxmox als Virtualisierungsplattform
- Nextcloud für die Dateiablage
- UrBackup für die Sicherung wichtiger Nextcloud-Daten
- Proxmox-Backups für die Wiederherstellung der Container
- Uptime Kuma für Monitoring
- VPN-Zugriff für die Verwaltung
- dokumentierten Wiederanlauf und Restore-Tests
